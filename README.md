# Programmable Pixels

## What you have

A reader (`reader.js`), a catalogue of gizmos (`index.html` + `gizmos/` +
`catalogue.json`), and GIZMO.md — the law every gizmo was made under.
Why it exists: [the manifesto](manifesto.md). Reading it by machine: [api.md](api.md).

## How to run it

Open `index.html`, or push this repo to GitHub Pages. No build step, no
server, no dependencies.

## How to make one

Read [GIZMO.md](GIZMO.md); add a folder; the reader picks it up. A gizmo is
one JSON file — typed ports, a body of maths, DNA saying why it exists.

## Labels

Ours are ours; yours are yours. Ids are content hashes and travel; labels
are local and do not.
